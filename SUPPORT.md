# Support

This repository is a template, not a hosted service. Before requesting help, run the documented checks and capture the exact failing command, tool versions, operating system, and smallest reproduction.

When the repository is hosted, use its issue tracker if enabled for reproducible template defects. Use the repository's established maintainer channel for questions that should not be public. Do not post credentials, secrets, private input, or vulnerability details; follow `SECURITY.md` for security reports.

A project copied from this template should replace this file with its own verified support scope and contact channels.
