# Security Policy

## Supported Versions

This template has no published release. Security fixes are applied to the current `main` branch.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Copied or modified templates | Maintained by their owners |

## Reporting

Do not disclose a vulnerability or secret in a public issue. When the repository is hosted, use its private vulnerability-reporting channel if enabled; otherwise contact the repository maintainers privately through an established channel. A copied template should replace this paragraph with its own verified contact method before publication.

Include the affected revision, impact, reproduction steps, and any suggested mitigation. Do not include real credentials or private user data.

## Boundary

The included tool is local-only and has no authentication, persistence, hosted service, Worker, or MCP transport. Projects that add those capabilities must define and test their own trust boundaries.
